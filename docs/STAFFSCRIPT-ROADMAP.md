# StaffScript Roadmap

## v0.1 Foundation

- Official language name: StaffScript.
- `.staff` as preferred extension, `.staff.txt` for simple text sharing.
- Notes, rests, durations, bars, slurs, dynamics, expressions, tempo, metadata, sections, motifs, repeats, and chord mode subset.
- MusicXML remains the canonical export/rendering target.

## Near-Term

- More precise MusicXML expression/articulation export.
- Better section and rehearsal mark engraving.
- Parser fixture snapshots for expanded StaffScript examples.
- Project import/export for `.staff` files.
- Sample project regeneration script.

## Later

- MIDI export and basic playback.
- Relative pitch and key-aware spelling helpers.
- Multi-track and multi-instrument arrangements.
- DAW export experiments.
- Humanization controls.
- AI-assisted composition workflows that can reason over motifs, form, and variation.
